# reviews/

Output of the scheduled evidence reviewer (see [`../docs/11-evidence-watch.md`](../docs/11-evidence-watch.md)).

One dated note per run in which new papers appeared. `reviewed-pmids.json` is the
reviewer's memory of what it has already looked at.

**Nothing in this directory is a conclusion.** These are triage notes on papers the
automated PubMed query surfaced. Any note that proposes changing a claim does so under
a "RECOMMENDED EDITS" heading, and a person applies it — the reviewer is explicitly
forbidden from editing `docs/01` through `docs/12`.

Most runs will correctly conclude that nothing changed.
